The address is a Firefox Relay alias: Mozilla Corporation, USA, receives the message and forwards it to me, as described in the Mozilla privacy notice.

The editor

The editor runs in your browser. Files you open from your computer are read there and never uploaded. While a file has changes you haven't saved, the editor keeps a draft of it in your browser's local storage, on your device only, so that reloading the page doesn't lose your work. Saving the file deletes the draft, and clearing this site's data in your browser deletes all of them. The editor also remembers there whether its source pane and its inspector are open. None of this is sent to the server or anyone else.

A file can ask to load fonts, stylesheets or images from other services. The editor blocks those requests, so opening a file never contacts another service.

Links to other sites

The site loads no fonts, scripts or images from other services. Links to GitHub, npm and other sites lead to services with their own privacy policies.

Your rights

I keep no data about visitors myself. The only exception is email: if you write to me, I have your message and address until they're no longer needed. GitHub's logs aren't visible to me, so questions about them go to GitHub, as described in the GitHub Privacy Statement.

Under the GDPR you can ask whether I hold data about you and for a copy of it (Art. 15), and have it corrected (Art. 16), deleted (Art. 17) or its processing restricted (Art. 18). Because the processing described here rests on legitimate interests, you can also object to it (Art. 21). Write to the email address above. If you haven't written to me before, the answer will be that I hold nothing about you.

You can also complain to a data protection authority, for example the one where you live.

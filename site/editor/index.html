CSSV Editor

Edit the table, keep the text.

Open a .cssv file to see its table and its text side by side. Edit cells, sort rows and add styles in the table, or type in the text, and each one updates the other. Every change is written into the file as CSV and CSS, and the rest of the file stays exactly as it was. The editor runs in your browser, and nothing you open is uploaded.

or drop a .cssv or .csv file on this page

Arrow keys move between cells. Enter or F2 edits a cell, and typing replaces its value. Ctrl+C, Ctrl+X and Ctrl+V copy, cut and paste. Shift+F10 opens the cell's menu, Ctrl+F finds, Ctrl+P previews the printed table, and Ctrl+/ lists every shortcut. Styles apply to the selection: select a column's letter to style the column, or everything to style the table.

Searches values as the file has them.
